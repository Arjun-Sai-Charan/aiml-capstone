# Project instructions

Build AIML-02 as a cross-platform educational medical imaging project. Use the root `.venv` Python 3.12 and run tasks through `python run.py <task>`. Use pathlib and environment variables RSNA_DIR/MSD_DIR. Never download or commit raw data or model weights. Every UI and README includes **For education only, not clinical use.** Mark unavailable results PENDING with exact commands. Follow the six project phases in the user-provided specification.
